# Blocopoly

## Description

A clone of Monopoly with all the standard game mechanics and planned additional modes and mechanics, including other economic states, punishments, and cooperative gameplay through partnerships and discounts.

- Read [FEATURES.md](FEATURES.md) for a brief summary of planned/upcoming drops.
- Read [DESIGN.md](DESIGN.md) for a high-level overview of the architectural design and conventions in this project if you would like to contribute.

## Setup

**Prerequisites:** Node.js 20+

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

**Other commands:**

```bash
npm run build   # Production build
npm run start   # Run the production build locally
npm run lint    # Lint the codebase
```

Install prettier extension. A prettier config exists for linting and formatting.
